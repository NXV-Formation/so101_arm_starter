# Learning with limited labels

This repository gathers practical codes illustrating traditional and modern approaches when annotations are scarce.

1. Semi-supervised clustering
2. Self-training with pseudo-labels using XGBoost
3. Mean Teacher
4. Contrastive learning by SimCLR
